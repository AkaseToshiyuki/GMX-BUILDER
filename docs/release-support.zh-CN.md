# GMXBUILDER 1.0.0 脂质支持范围

<p><a href="release-support.md">English</a> · <strong>简体中文</strong></p>

GMXBUILDER **1.0.0** 分发 **V4 脂质库**，含 37 个已准入的脂质/后端组合和 134,000 个构象。[机器可读矩阵](../src/gmxbuilder/data/prebuilt_assets/support-matrix.json) 逐项记录构象数量及验证范围。软件与资产分别版本化，安装和运行时均检查兼容性。

V4 表示脂质库体系。分发清单中的 `asset_version: 7` 表示资产包修订号 7，不是“V7 库”。

## 已分发组合

| 后端 | 组合数 | 脂质 |
| --- | ---: | --- |
| Lipid21 / Amber14SB | 9 | DOPC, DOPE, DOPS, DPPC, DPPE, POPC, POPE, POPS, PSM |
| GAFF2 / Amber14SB | 1 | POP2 |
| CHARMM36m | 14 | CHOL, DOPC, DOPE, DOPS, DPPC, DPPE, POP2, POP3, POPC, POPE, POPG, POPI, POPS, PSM |
| CHARMM36 | 13 | CHOL, DOPC, DOPE, DOPS, DPPC, DPPE, POP3, POPC, POPE, POPG, POPI, POPS, PSM |

37 指后端组合数，不是 37 种不同脂质。部分 CHARMM36 条目在已验证的参数等价契约下复用 CHARMM36m 坐标，不代表额外独立采样。混合膜必须满足每个组分的参数及后端契约。注册表共 336 个脂质/来源组合，其余 299 个未作为已准入构象库分发；注册表存在条目不保证化学兼容，也不承诺未来必然支持。后续资产版本可以逐步扩大已验证子集。

## 科学范围

所有 37 个条目均作为**初始化构象**准入。分子身份、参数指纹、坐标/拓扑原子顺序、几何、来源、独立重复及局部构象检查保留在逐条元数据中。它们不证明整体膜达到平衡、平衡构象权重、定量平衡面积或用户生产模拟的收敛性；新系统必须按其组成和条件重新平衡。GAFF2 POP2 在记录的 POPC 宿主环境采样，不证明纯 POP2 膜的平衡性质。

归档另含 67 个当前 GAFF2/AM1-BCC 参数缓存；它们不是额外的已准入构象库，也不会解锁尚未通过的条目。缺少证据或分子身份、参数、协议不兼容的资产保持不可用，程序不会静默回退到未验证的内置几何。

## 安装与兼容性

通过安装器获取归档和单独分发的力场，再查看实际安装状态：

```bash
gmxbuilder prebuilt-assets status
gmxbuilder lipid-library status
```

资产清单固定归档大小及 SHA256。归档包含构象、证据元数据和 GAFF2 参数缓存，不包含单独下载的力场数据库。干净安装需要同时满足这些前提。升级保留较新的有效缓存；实际安装后的目录状态是可用性的依据。

读取器支持两种经验证的 CHARMM 安装布局：旧补充文件名和当前带 `gmxbuilder-` 前缀的文件名。仅固定内容哈希可识别为等价；系数变化、缺文件或新旧文件并存不能继承旧身份。已检查入口指令及 36 个保留 TPR 的完整拓扑/输入参数相等，原始证据指纹不变。

现有 PSM 预处理例外只适用于经审查的 128-PSM/TIP3P/等量 NaCl、GROMACS 2026.3 单精度情况。提供 PSM 初始化构象不等于允许任意大小、混合物、工具版本或其他电荷问题的预处理警告；用户构建的系统必须通过自身检查。

## 发布边界

五类应用工作流在各自分子和参数边界内提供。本矩阵只描述全原子脂质子集；Martini 3 有独立的能力列表。不支持的组合继续明确拒绝。构建检查及软件测试不替代物理验证。安装 1.0.0 不会启动或恢复脂质模拟队列。
